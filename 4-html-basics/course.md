# HTML

Audio tag comes with a control attributes that's very important. 
A local link starts with a name attributes (TopOfThePage) and refers as a id (#TopOfThePage).
Video tag is better with height and width. An autoplay attribute is necessary to automatically run a video.
Iframe tag is useful for online videos like on Youtibe. Just a src and it's enough.

Can change a list styling by addiing `type` attribute as `disc` or `square` in the top parent tag.
For ordinared list, a type `I` will just change from arabic numbers to roman ones.

We also have a description list that I don't know. With dl and inside a dt and dd tags.


Div is the most important. It's like a section a bag where you can put anything you want.


Tables :
- start with table tag;
- then have two bigs parts : thead and tbody as an html page;
- thead have th as columns names;
- tbody have tr for a row and then td for a description for each columns in range.


Semantic HTML = adding meaning and also useful for SEO or search engines.
Three differents parts/tags :
- header (main);
- main (section, aside, article);
- footer.

Two more uses semantic html tags are : aside and figure.


Form
Receiving inputs from user, then collecting websites data. Create with a form paired tags.
The most import elements here is an input tag. it comes with two stuff : type and name.
Name is of future reference to the input element. By type is to define the expcectation : text, link, mail.

We also have others elements in forms like selection input, text area and buttons.
Buttons is to generate actions after filling the form. Can have three types values : 
- submit : send data to a server;
- reset : just re-iit;
- button : no initial behavior.
